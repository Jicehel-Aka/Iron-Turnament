# Archive

Fichiers **non utilisés** par le jeu (web ou AKA), conservés au cas où. Déplacés avec `git mv` : l'historique est intact.
Rien ici n'est référencé par le code ; on peut les remettre à leur place d'origine si besoin.

- `portraits-anciens/` : anciennes versions des portraits (dont les premiers Kenji et Krowen, remplacés par des
  personnages originaux) et le jeu de portraits `fighter_*_portrait_*`.
- `aistudio-medias/` : médias temporaires générés par AI Studio (`.aistudio/.../.tempmediaStorage`).
- `aistudio-public/` : images d'AI Studio qui étaient dans `public/assets/aistudio`.

Attention : `portraits-anciens/` contient les premiers Kenji et Krowen, dont le design rappelait des personnages existants ;
ne pas les remettre dans une diffusion publique.
